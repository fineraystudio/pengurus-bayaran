Kemas kini terakhir: 27 Oktober 2026

Ringkasnya: kami tidak mengumpul, menyimpan atau menghantar data anda. Semua berlaku dalam pelayar anda. Tiada kuki, tiada analitik dan tiada penjejakan.

Data yang dikumpul

Tiada. Pengurus Bayaran tidak meminta akaun, e-mel atau kata laluan, dan tidak menghantar sebarang maklumat peribadi ke pelayan kami atau pihak ketiga.

Cara aplikasi berfungsi

Pengurus Bayaran ialah satu halaman web yang berjalan sepenuhnya dalam pelayar anda:

  • Nama bayaran, amaun, tarikh dan status yang anda masukkan tidak pernah meninggalkan peranti anda.
  • Pengiraan zakat dan penukaran tarikh Hijrah dibuat secara tempatan dalam pelayar.
  • Fail eksport JSON dijana dalam pelayar dan dimuat turun terus ke peranti anda.
  • Selepas lawatan pertama, aplikasi boleh berfungsi luar talian melalui service worker.

Penyimpanan tempatan

Data anda disimpan dalam localStorage pelayar di bawah kunci pengurusBayaranData_v1, pada peranti yang anda gunakan sahaja. Kami tidak dapat melihat atau mengaksesnya. Anda boleh memadamkannya bila-bila masa dengan mengosongkan data laman ini dalam tetapan pelayar, atau dengan memadam aplikasi daripada skrin utama. Simpan fail eksport JSON jika anda mahu salinan sandaran sebelum berbuat demikian.

Analitik dan kuki

Kami tidak menggunakan kuki, analitik (seperti Google Analytics), rangkaian pengiklanan, piksel media sosial atau sebarang bentuk penjejakan pengguna.

Perkhidmatan pihak ketiga

Aplikasi ini tidak memuatkan skrip, fon atau perpustakaan daripada CDN pihak ketiga. Halaman dihoskan di GitHub Pages; seperti mana-mana pelayan web, GitHub mungkin merekod maklumat teknikal asas (alamat IP, jenis pelayar) untuk tujuan keselamatan dan penyalahgunaan. Lihat dasar privasi GitHub untuk maklumat lanjut.

Kanak-kanak

Aplikasi ini selamat untuk semua peringkat umur kerana tiada maklumat peribadi dikumpul daripada sesiapa, termasuk kanak-kanak di bawah 13 tahun.

Perubahan pada dasar ini

Jika dasar ini berubah, tarikh "Kemas kini terakhir" di atas akan dikemas kini dan perubahan akan disertakan dalam sejarah projek.
